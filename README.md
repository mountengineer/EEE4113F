# EEE4113F
This repository holds all of the code used to develop the ItsyBitsy MCU for the purposes of the Sensing and Digital Signals Processing subsystem in Project ICICLE.

## Main code 
The code aimed for the normal functioning of the MCU is found in VSCode/EEE4113F/.

## Matlab Code
The Matlab code used to generate tests, reference implementation and comparison functions can be found in MATLAB/.

## MCU Testing Code
The VSCode2/Test/. directory contains a cloned copy of the main code which prints specifically only number outputs. This was made to port outputs to Matlab for better plotting and verification.
